Install on Linux

  1. Add the JobDocs repository: 
    flatpak remote-add --user --from jobdocs https://i-machine-things-org.github.io/JobDocs/jobdocs.flatpakrepo
  2. Install the app: 
    flatpak install jobdocs io.github.i_machine_things.JobDocs
  3. Or click Add Flatpak Repository above — KDE Discover will prompt you to add it and install automatically.
